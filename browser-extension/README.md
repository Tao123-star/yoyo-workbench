# 桃子工作台平台数据同步器

该 Chrome 扩展只读取已登录创作者后台中可见的作品统计，并将清洗后的标题、日期、观看、点赞、评论、收藏、分享等数字交给 `workbench.taozipipi.cn` 保存。

它不会读取、导出或上传密码、Cookie、验证码、浏览历史和其他网站数据。

安装方式：Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。安装权限确认属于用户操作，Codex 不会代替确认。

安装后刷新工作台和两个创作者后台页面。工作台每天首次打开会尝试同步一次，也可以在“自媒体中心 → 数据复盘”点击“立即同步”。
