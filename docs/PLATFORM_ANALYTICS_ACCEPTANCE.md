# 平台数据自动同步验收报告

验收日期：2026-08-20  
正式站：<https://workbench.taozipipi.cn>

## 交付范围

- Chrome 本机同步器从已登录的抖音创作者中心、小红书创作服务平台读取可见作品统计。
- 工作台通过受保护的 `PUT /api/platform-analytics` 保存账号所属数据，通过 `GET /api/platform-analytics` 在电脑和手机端读取。
- 每台安装同步器的电脑每天首次打开工作台自动同步一次，并保留“立即同步”手动入口。
- 手机端只读取云端结果，不需要安装浏览器扩展。

## 真实数据验收

- 抖音：成功读取并保存 60 条作品；最新工作台作品数据为播放 4,805、点赞 99、评论 17、收藏 87、分享 12。
- 小红书：成功读取并保存 10 条作品；最新工作台笔记数据为观看 318、点赞 3、评论 0、收藏 6、分享 1。
- 双平台汇总和 70 条作品在“自媒体中心 → 数据复盘”中同时展示。
- 390 × 844 手机视口重新加载后，从云端读取到抖音、小红书汇总及作品表，无控制台错误。
- 同一天再次刷新前后云端更新时间均为 `08/20 00:37`，没有重复触发平台采集；“立即同步”入口仍可用。

## 安全边界

- 扩展权限仅限工作台、抖音创作者中心和小红书创作服务平台。
- 不读取或上传密码、Cookie、验证码、浏览历史、`localStorage` 或 `sessionStorage`。
- 平台页面结构变化或登录过期时，同步会给出错误提示；已有云端数据不会被清空。
