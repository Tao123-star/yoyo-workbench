# 素材库智能解析演示与验收记录

验收日期：2026-08-15  
线上地址：<https://workbench.taozipipi.cn>

## 演示步骤

1. 登录桃子工作台，进入「素材库」。
2. 点击「新增记录」，选择「抖音 / 小红书等内容链接」或「网站」。
3. 粘贴 `http` 或 `https` 链接，点击「智能解析」。
4. 检查并修改标题、作者、来源、发布时间、封面、摘要和正文预览。
5. 点击「保存到素材库」。只有这一步才会正式写入本地缓存并触发账号云同步。

抖音、小红书等页面若要求登录或启用反爬限制，界面会保留原链接并显示失败原因，用户仍可手动填写后保存，不会伪造解析结果。

## 已验收范围

- 服务端使用 metascraper 提取网页元数据，使用 Mozilla Readability 提取正文。
- 解析接口要求已登录账号，并执行同源校验和每分钟限流。
- 阻止 localhost、私网 IP、链路本地地址、云元数据地址和含账号密码的 URL。
- 每次重定向都重新执行地址校验；限制重定向次数、请求时间、HTML 类型和 2 MB 响应体积。
- JSDOM 不执行目标页面脚本；返回字段经过长度限制，封面仅接受 HTTP(S) 地址。
- 自动结果进入可编辑预览区，用户确认保存后才进入 `yoyo_captures`。
- 新增字段参与素材搜索，并随现有账号数据同步；现有快速记录、图片保存和创作链路保持不变。
- 手机版 390 px 实测无横向溢出、无 JavaScript 报错。

## 验证结果

- `node --check`：认证服务、解析器、云同步、素材数据层和前端应用均通过。
- `node --test`：6/6 通过，覆盖正文提取、无标题回退、非 HTML、超大响应、超时、私网拦截、未登录 401 和素材字段持久化。
- `git diff --check`：通过。
- 服务镜像内真实解析 `https://example.com`：成功提取 `Example Domain` 和正文。
- 公网健康检查：`/api/auth/health` 返回 `200`、`configured: true`。
- 公网访问控制：未登录请求 `/api/link-preview` 返回 `401`；受保护页面继续跳转登录页。
- 生产容器：`workbench-auth` 与 `gateway-caddy` 均保持运行。
